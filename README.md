# EcoPulse - Система мониторинга ESG-репутации

> Система раннего обнаружения экологических и социальных скандалов, связанных с крупными компаниями, на основе анализа локальных веб-каналов и региональных медиа.

---

## Идея

EcoPulse - это интеллектуальная система раннего обнаружения репутационных угроз для промышленных компаний. Она мониторит локальные VK-паблики и RSS-ленты СМИ, выявляет критические инциденты (экология, трудовые конфликты, обман) и оповещает PR-команду за 15 минут вместо стандартных 2–3 суток. Это позволяет реагировать на угрозы до того, как они попадут в федеральные СМИ.
---

## Основные возможности

* Мониторинг 24/7 - 120+ VK-пабликов, 15+ RSS, 6 новостных сайтов, сбор каждые 15 минут

* Умная фильтрация - RuBERT классифицирует угрозы (critical / not_critical)

* Мгновенные алерты - Telegram-бот с краткой выжимкой и ссылкой

* Дашборд - Streamlit-аналитика + сбор фидбека (👍/👎) для дообучения

* Прогноз реакции - GigaChat генерирует рекомендации для PR-команды
---

## Решаемая бизнес-проблема

Информация об инцидентах сначала появляется в малых каналах (500-3000 чел.)
PR-команды узнают о них с опозданием → скандал уже в федеральных СМИ
Последствия: штрафы до 3-5х, падение капитализации на 1-2%, потеря контрактов

## Технологический стек

* ML: RuBERT-tiny2 (fine-tuned), ONNX Runtime (CPU, ≤ 200 мс/пост)
* Данные: 705 тыс. размеченных постов (отзывы, токсичные комментарии, гео-отзывы)
* Аугментация: synonym replacement, синтетические ESG-посты от GigaChat
* Активное обучение: дообучение при накоплении 200 фидбеков
* Мониторинг дрейфа: PSI-метрики, HTML-отчёты
* Инфраструктура: Docker, парсеры (RSS, VK API, BeautifulSoup), Streamlit, Telegram Bot API
